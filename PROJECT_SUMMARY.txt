================================================================================
  🚀 HOW TO RUN
================================================================================

FASTEST WAY (Recommended):

Windows:
  1. Open Command Prompt or PowerShell
  2. cd e:\AI Projects\house-price-prediction
  3. run.bat
  4. Wait 10-15 seconds for both windows to open
  5. Open your browser and go to http://localhost:3000

Linux/Mac:
  1. Open Terminal
  2. cd ~/path/to/house-price-prediction
  3. chmod +x run.sh
  4. ./run.sh
  5. Open your browser and go to http://localhost:3000

================================================================================
  🆘 TROUBLESHOOTING
================================================================================

Issue: run.bat doesn't work
Solution: Read QUICK_START.md for manual setup

Issue: "Port already in use"
Solution: Kill existing processes on ports 3000 & 5000

Issue: "Module not found" error
Solution: Run: pip install -r backend/requirements.txt

Issue: Frontend not connecting to backend
Solution: Make sure backend is running on http://localhost:5000

Issue: Dependencies won't install
Solution: Update pip, try pip install --upgrade -r requirements.txt

More solutions in QUICK_START.md
